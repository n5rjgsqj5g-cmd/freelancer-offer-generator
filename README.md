# Freelancer Offer Generator

A privacy-first, local-first browser tool for turning user-provided facts into
a clear first draft of a freelancer offer. It has no backend, no login, no ads,
no tracking, and exports a plain-text draft directly in the browser.

## Use it

Open the standalone live tool at
[Freelancer-Angebots-Generator](https://n5rjgsqj5g-cmd.github.io/freelancer-offer-generator/).

It is also included in the [SERS Practical Kits collection](https://n5rjgsqj5g-cmd.github.io/sers-money-router-live/freelancer-angebots-generator.html).

Or download this repository and open `index.html` locally.

## What it does

- collects only the facts the user enters locally;
- generates a structured draft with scope, price, limits, and next step;
- copies the result or downloads it as a UTF-8 text file;
- never sends the draft to a server.

The tool provides communication structure, not legal, tax, or contract advice.
